# jniLibs — motor OpenVPN

Librerías nativas integradas (arm64-v8a, armeabi-v7a, x86, x86_64):

- libovpnexec.so  — launcher
- libopenvpn.so   — OpenVPN 2.x
- libovpn3.so     — OpenVPN 3
- libovpnutil.so / libosslutil.so / libosslspeedtest.so

**Licencia:** suelen proceder de ics-openvpn / OpenVPN (GPL).  
Si distribuyes la app con estas libs, revisa las obligaciones de licencia (a menudo publicar código fuente).

Credenciales en `public/vpn/credentials.txt`.
